- Jackson 2.22.4 (jackson-core, jackson-databind, jackson-annotations,
  jackson-datatype-jsr310, jackson-dataformat-yaml), the parser of JSON files
  and of the configuration file, and of the schemas of Arrow
  https://github.com/FasterXML/jackson
  Apache License 2.0, see apache-2.0-LICENSE.txt and jackson-NOTICE.txt.
  jackson-core includes FastDoubleParser and Schubfach, see
  META-INF/FastDoubleParser-LICENSE, META-INF/FastDoubleParser-ThirdParty-LICENSE
  and META-INF/Schubfach-LICENSE.

- SnakeYAML 2.5, which Jackson reads YAML with
  https://bitbucket.org/snakeyaml/snakeyaml
  Apache License 2.0, see apache-2.0-LICENSE.txt.

- JSqlParser 5.4, the parser of SQL
  https://github.com/JSQLParser/JSqlParser
  Dual-licensed under the GNU Lesser General Public License 2.1 and the

- FastCSV 4.4.0, the reader of CSV files
  https://github.com/osiegmar/FastCSV

- Janino 3.1.20 of janino-lts (janino, commons-compiler), which compiles
  expressions
  https://github.com/janino-lts/janino

- Apache Parquet Java 1.18.1 (parquet-hadoop, parquet-column, parquet-common,

- aircompressor 2.0.3
